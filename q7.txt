Authentication & Security
7.	What is JWT authentication? What exactly did you implement using JWT in your project?
8.	How does authentication work? How did you design and implement the authentication solution in your project?
9.	Suppose there are thousands of user records and someone tries to hack or abuse the system. How would you protect the application and prevent unauthorized access or attacks?
10.	What is hCaptcha or reCAPTCHA? Why and where would you use it in an application?
11.	What is Cross-Site Scripting (XSS)? How can you prevent XSS attacks in a web application?
12.	What is the difference between innerHTML and textContent? When would you use each one?
13.	What is dangerouslySetInnerHTML in React? What are its risks, and in which scenarios would you use it?
14.	Where do you store the authentication token? What are the different approaches for storing tokens securely?
15.	How can you store an authentication token on the client side? What are the security considerations for each approach?
React & Frontend

17.	What is a dependency array in useEffect? How does it affect the execution of the effect?
18.	What are useMemo and useCallback? What is the difference between them, and when would you use each one?
19.	What are the drawbacks or potential disadvantages of using useMemo and useCallback?
API Integration
